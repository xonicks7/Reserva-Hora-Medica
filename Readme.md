## Estrategia de trabajo colaborativo

Se utiliza Kanban para organizar las tareas del proyecto.

### Flujo de trabajo con Git

1. Crear una rama para cada actividad.
2. Realizar modificaciones en los archivos.
3. Registrar cambios mediante commits.
4. Subir la rama a GitHub.
5. Crear un Pull Request.
6. Revisar y fusionar los cambios en main.

### Comparación de metodologías

- Scrum: trabaja mediante iteraciones llamadas sprints.
- Kanban: organiza las tareas mediante un tablero visual
  y permite un flujo de trabajo continuo.
