
# Proyecto DevOps - Reserva Médica

## Descripción
Aplicación web estática para simular la reserva
de horas médicas utilizando Nginx y Docker.

## Tecnologías
- HTML
- CSS
- Nginx
- Docker
- Docker Compose

## Requisitos
- Docker Desktop
- Git

## Instalación
Clonar el repositorio:

git clone URL_DEL_REPOSITORIO

Ingresar a la carpeta:

cd reserva-medica

## Ejecución

docker compose up -d --build

## Verificación

Abrir en el navegador:

http://localhost:8080

## Logs

docker compose logs

## Detener aplicación

docker compose down

## Seguridad
No ingresar datos personales ni credenciales reales.
